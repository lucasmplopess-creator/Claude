SEC 04

As três decisões que definem se os números estão certos

Erros mais frequentes em painel de estoque

1. O snapshot de estoque nunca é somado ao longo do tempo

A tabela de posição guarda o saldo de cada dia. Somar um trimestre inteiro multiplica o estoque por noventa. Toda medida de saldo retorna apenas a última data com dados dentro do período filtrado. Este é o erro mais comum e o mais difícil de perceber, porque o número continua parecendo plausível. 

Valor Estoque =
CALCULATE (
    SUM ( fPosicaoEstoque[ValorSaldo] ),
    LASTNONBLANK ( dCalendario[Data], CALCULATE ( COUNTROWS ( fPosicaoEstoque ) ) )
)

2. Transferência entre depósitos é saída, mas não é consumo

Se a transferência entrar no cálculo, o giro sobe, a cobertura cai e a curva ABC classifica como item crítico o material que apenas mudou de prateleira. A dimensão de tipo de movimento carrega a marcação ContaConsumo, e giro, cobertura, consumo médio, curva ABC e curva XYZ filtram por ela. Na base de exemplo as 578 transferências inflam o giro em 1,3% quando o filtro é removido, de 5,49x para 5,56x. O desvio cresce na mesma proporção do volume transferido entre depósitos. 

Valor Consumo =
CALCULATE (
    SUM ( fMovimentacaoEstoque[ValorTotal] ),
    dTipoMovimento[ContaConsumo] = TRUE ()
)

Giro 12 Meses =
VAR _EstoqueMedio =
    CALCULATE ( [Estoque Médio Valor],
        DATESINPERIOD ( dCalendario[Data], MAX ( dCalendario[Data] ), -12, MONTH ) )
RETURN DIVIDE ( [Valor Consumo 12M], _EstoqueMedio )

3. As flags de nível de serviço são resolvidas na origem, não em DAX

Atendido integralmente, no prazo e OTIF viram colunas de dois valores na view SQL. O VertiPaq comprime colunas assim com eficiência máxima, o que reduz o modelo e transforma o cálculo de OTIF em uma contagem filtrada em vez de um iterador linha a linha sobre centenas de milhares de requisições. 

-- na view bi.vw_Requisicao
CASE WHEN QuantidadeAtendida >= QuantidadeSolicitada
      AND DataAtendimento <= DataPrometida THEN 1 ELSE 0 END AS FlagOTIF

// no modelo
OTIF % = DIVIDE (
    CALCULATE ( COUNTROWS ( fRequisicaoItem ), fRequisicaoItem[FlagOTIF] = 1 ),
    COUNTROWS ( fRequisicaoItem )
)
